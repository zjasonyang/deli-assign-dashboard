# Deli assign dashboard

在本機執行的派工日曆。使用 Python 3.12 標準函式庫與 SQLite，不需要安裝額外套件。

## 啟動

```sh
cd ~/playground/deli-assign-dashboard
python3 server.py --port 8765
```

開啟 http://127.0.0.1:8765 。服務僅監聽本機，不對區域網路開放。前端需透過此服務開啟，直接開啟 HTML 檔無法登入或取得資料。

預設本機測試帳號如下。

| 帳號 | 密碼 | 權限 |
| --- | --- | --- |
| admin | admin123! | 編輯全部工單欄位與排程、管理人員 |
| user | user123! | 查看日曆與工單詳情、修改備註 |

若要設定其他初始密碼，可在第一次啟動前設定 `DELI_ADMIN_PASSWORD` 與 `DELI_USER_PASSWORD`。既有帳號不會因環境變數或重啟而被覆寫。本版沒有帳號管理或變更密碼介面。

## 淺色版本

開啟 `http://127.0.0.1:8765/?theme=light` 即為固定淺色背景版本，登入頁、日曆及工單詳情都使用淺色。暫時外部網址同樣可加上 `?theme=light`。原本不帶參數的入口仍依系統設定切換深淺色，兩個入口共用資料與登入。

## 日曆與派工

- 週曆與月曆的日期方向一致，週一到週日由左至右。週曆以北部 A、南部 A、南部 B 為三個團隊列。
- 三個團隊各自獨立收合，可同時展開多組；預設展開北部 A，並記住瀏覽器的開關設定。收合時保留每天件數與急件提示，點件數可展開。另提供全部展開及全部收合。展開後每組每天至少保留 5 張工單的高度，超過 5 件繼續延展。工單依出勤時間排序。
- 週曆維持可閱讀的欄寬。窄視窗在日曆區左右捲動，團隊欄固定在左側，不把七天縮成窄欄或改成直排。
- 工單詳情使用週曆上方全寬空間。桌面將基本資料、內容與備註、排程橫向分欄；窄視窗分兩欄，手機依序排列。點選工單時待排清單先收起，關閉詳情後再展開。
- admin 可按「建立新工單」開啟橫向表單，儲存後由後端產生工單編號。可先存入待排清單，或連同排程一起建立；排程衝突時整筆建立會回滾。user 沒有建立權限。
- 點選待排或已派工工單可查看人員(主)、人員(從)、項目名稱、地址、聯絡電話與內容。電話支援點選撥號，內容保留換行；未填資料顯示「未指派」或「未提供」。admin 可編輯全部工單欄位與排程；user 僅能編輯備註，其他工單資料以唯讀方式顯示。後端逐欄驗證權限，拒絕含有其他欄位的 user 更新。
- 後端檢查日期、時間、工單、團隊與人員，以及同團隊同時段衝突。工單欄位與排程一次儲存，任一驗證失敗便全部回滾。相鄰時段可以安排，不含跨日派工或交通時間規則。
- 月曆點選日期可切回該週；工單過多時提供其餘筆數。團隊與狀態篩選共用於兩種視圖。
- 窄視窗初次載入與按「今天」會將今天捲入可見範圍；關閉詳情會回到原本的工單。寬螢幕捲動時固定日期表頭，窄視窗則在展開的格子內補上日期。
- 月曆可見工單與其餘筆數都會提示急件。手機可展開左上角縮寫說明，人員高亮按鈕只顯示縮寫，完整姓名保留在按鈕提示中。

## 未儲存內容與連線中斷

切換工單、關閉詳情、登出或離開頁面前，若有未儲存變更會先確認。輸入欄位內按 Esc 不會關閉詳情。手機點工單時先聚焦詳情標題，避免直接聚焦輸入欄位。

草稿依帳號暫存在目前分頁的 `sessionStorage`；登入逾時後，在同一分頁重新登入原帳號會回填，仍須按儲存才會寫入後端。登入其他帳號不會載入原帳號的草稿，跨分頁切換登入身份後重新載入資料也會清除舊身份的編輯器。草稿不是跨裝置備份，關閉分頁後不保證保留。

服務中斷或 tunnel 回傳非 JSON 錯誤時，畫面提供中文訊息與重試，不會當成登出。儲存途中繼續輸入的內容會保留；工單已建立但重新讀取失敗時，重試不會再次建立同一張工單。

## 人員管理與縮寫

預先建立「人員 1」至「人員 6」，固定縮寫為 P1 至 P6。admin 在「人員(主)」與「人員(從)」下拉選單中指定人員，不可選擇同一位人員兩次。尚未指派時可留空。

點右上方 `admin` 帳號即可開啟管理選單，選擇「人員管理」前往 `/admin/personnel`，可新增或更改姓名、縮寫。縮寫為 1 至 8 字且大小寫不敏感唯一；新增時可留空由系統產生。姓名更新後，關聯工單會同步顯示，縮寫不會因改名重設。user 無法開啟管理頁或寫入人員 API。

卡片只顯示人員縮寫，表單保留主從欄位名稱。展開／收合控制旁列出人員，點選一位人員會高亮其相關工單、淡化其他工單，並暫時展開本週或本月有相關工單的團隊，不覆寫原本記住的收合設定。再點同一人或「全部人員」可取消。週曆、月曆、待排卡片及收合摘要共用此高亮狀態；淡化卡片仍可操作。

表格左上提供縮寫說明：北A為北部 A 組、南A為南部 A 組、南B為南部 B 組、急為急件、WO為工單編號。

## 資料與身份

`data/deli.sqlite3` 儲存帳號、sessions、團隊、工單與派工。初始化時由 `seed.json` 載入目前台灣日期所在週的示意資料，包含同一天同一組 5 件工單。後續啟動不會重新匯入或覆蓋資料。舊版資料庫會自動加入工單詳情欄位並保留原資料，尚無資料的新欄位留空。人員欄位遷移成 ID 關聯，既有自訂姓名會建立對應人員，備註初始為空白，重啟不會重設。畫面資料仍為示意資料，不含正式派工單來源。

密碼採隨機 salt 與 PBKDF2-SHA256 雜湊。登入後使用 12 小時的 HttpOnly、SameSite=Strict cookie，伺服器僅儲存 session token 的雜湊。角色由後端帳號資料決定；user 只能透過工單 API 更新備註，直接呼叫其他寫入 API 或混入其他欄位會被拒絕。登出會撤銷 session。寫入請求驗證 Origin，服務預設僅接受 localhost 或 127.0.0.1 的 Host，公開模式額外接受明確設定的 HTTPS 主機名稱。

本版供本機測試使用，伺服器本身使用 HTTP；暫時外部入口由 tunnel 提供 HTTPS。尚未提供正式部署、外部身份供應商或跨日派工。

## 程式分工

- `index.html`：登入、週月曆、工單詳情與派工編輯。沿用 shadcn 風格的中性色彩 token，尚未安裝正式 shadcn/ui 套件。
- `server.py`：HTTP API、身份與權限、SQLite 持久化、排程驗證。
- `seed.json`：首次啟動的示意資料。
- `tests/test_server.py`：實際 HTTP 請求的登入、權限、持久化、衝突與驗證測試。
- `tests/verify-browser.cjs`：以獨立暫存資料庫啟動服務，執行真實瀏覽器測試，不改動本機使用資料。

資料模型分為 `Team`、`Personnel`、`WorkOrder`、`Assignment`、`User` 與 `Session`。工單與派工紀錄分開；目前每張工單最多一筆派工，資料庫以 UNIQUE 約束避免重複。排程日期與時間採台灣當地時間，不以瀏覽器 UTC 換日。

## 驗證

```sh
python3 -m unittest discover -s tests -v
```

瀏覽器測試另需可用的 Playwright 與 Chrome。透過環境變數指定已安裝模組或執行檔，也可使用 Node 預設模組解析。

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright CHROME_PATH=/usr/bin/google-chrome node tests/verify-browser.cjs
```

瀏覽器測試涵蓋 1440、728、390px，淺色與深色，週曆、月曆與編輯器共 18 種組合。另驗證登入錯誤、admin 儲存、user 唯讀與 API 拒絕、重新整理及後端重啟後資料保留、時間衝突、草稿還原與帳號隔離、502 重試、儲存途中輸入、日期定位與人員高亮。截圖及結果寫入 `.verification/`。可加上 `REVIEW_FIXES_ONLY=1` 單獨執行這次 UI 審查的回歸檢查。手機軟鍵盤與螢幕閱讀器仍需實機驗證。

## 打包基底

```sh
python3 scripts/package.py
```

`dist/` 會產生 ZIP 及 SHA-256 校驗檔。ZIP 包含程式、種子資料、測試與檔案雜湊 manifest，不包含目前資料庫、session、暫時入口的密碼或執行檔。解壓縮後用 `python3 server.py` 啟動，首次啟動會建立示意資料與本機測試帳號。

## 暫時外部測試

可透過 Cloudflare Quick Tunnel 將本機服務接到暫時 HTTPS 網址。這次外部測試使用 `.runtime/preview.sqlite3` 的獨立資料副本，另產生 admin 和 user 密碼，並清除既有 session。外部測試的編輯不會回寫 `data/deli.sqlite3`。

伺服器的 `--public-origin https://完整主機名稱` 僅允許該 HTTPS 來源，並對公開請求使用 Secure cookie。公開模式會隱藏本機測試帳號提示，也會拒絕使用預設帳密啟動。建立新公開測試資料庫時，應先用環境變數設定新的帳密，再以公開模式啟動。

此次 tunnel 與外部測試後端最多執行 8 小時。主機關機、休眠、斷網或任一程序停止，都可能提早中斷；重新建立 tunnel 時網址會改變。關閉外部測試不影響原本的 8765 本機服務。

[Cloudflare Quick Tunnel 文件](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)
